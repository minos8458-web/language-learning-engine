미리보기에서 확인할 것

설치용 앱이 아닌 화면 확인용 파일이에요. 인터넷·로그인·실제 학습 기록 없이 합성 화면만 표시해요. 화면과 버튼이 휴대폰에서 잘 보이는지 확인해 주세요.

  1. ‘언어팩 선택’에서 나라·언어와 예시 용량을 확인해 주세요. 일본어 또는 중국어를 선택하면 팝업 아래에 Wi-Fi 권장 안내가 나와야 해요.
  2. 팝업에서 취소하면 목록으로 돌아가고, 다운로드를 누르면 가상 진행률 후 선택한 언어의 시작 화면이 나와야 해요. 진행 중에도 취소할 수 있어요.
  3. ‘언어팩 변경’으로 돌아가면 같은 파일은 다시 받지 않고 사용할 수 있어요. 파일을 다시 열면 가상 설치 상태는 초기화돼요.
  4. 휴대폰을 세로와 가로로 돌렸을 때 글자·카드·버튼이 잘리지 않는지 확인해 주세요.
  5. 위의 ‘살펴볼 화면’에서 시작·복습·새 문법·교차 연습·대화 연습 준비·학습 완료·연결 실패를 차례로 선택해 주세요.
  6. ‘새 문법’에서 ‘문법 학습 시작’을 누르면 같은 제안의 시작 버튼이 비활성화되는지 확인해 주세요.
  7. ‘대화 연습 준비’에서 다음 학습 확인 버튼을 누르면 완료 화면, 새 세션 버튼을 누르면 대화 준비 화면이 다시 나오는지 확인해 주세요.
  8. ‘교차 연습’에서는 세 표현이 같은 순서로 두 번 표시되는 것이 정상이에요. 아직 연결하지 않은 문제·답안 버튼은 비활성 상태예요.
  9. ‘연결 실패’는 합성 오류 화면이에요. 재시도해도 같은 오류를 보여주며 학습 완료로 바뀌지 않아야 해요.
